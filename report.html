Abstract

Long URLs are difficult to share, remember, and track across digital platforms. This project presents SnipLink, a client-side URL shortener web application built using HTML, CSS, and JavaScript. The system generates unique short codes using base62 encoding, persists link data via browser LocalStorage, and provides real-time click tracking and QR code generation. SnipLink features a modern glassmorphism UI with responsive design, animated counters, and toast notifications. The application demonstrates core software engineering principles including OOP design patterns, modular architecture, and iterative development with version control.

Problem Statement

Sharing lengthy URLs across messaging platforms, social media, and print media leads to broken links, poor readability, and an inability to track link engagement. Existing URL shorteners like Bit.ly require account creation and depend on external servers. There is a need for a lightweight, privacy-first URL shortener that works entirely in the browser without backend dependencies, while still offering analytics and QR code functionality.

Objectives

  1. Develop a client-side URL shortening system using base62 encoding for unique code generation.
  2. Implement persistent link storage with click tracking using browser LocalStorage.
  3. Provide auto-generated QR codes and one-click clipboard copy for every shortened URL.
  4. Build a responsive, visually appealing UI following modern web design principles.

Methodology / Approach

The project follows the Agile (Iterative) development model with incremental feature additions tracked via Git commits. The architecture uses an Object-Oriented design with three core classes.

Conclusion

This project successfully demonstrates the application of software engineering principles including Object-Oriented Design (three modular classes), iterative development with Git version control, and modern UI/UX design. The SnipLink URL shortener is fully functional, lightweight (no server required), and visually polished. Key learning outcomes include:

  • Applying OOP design patterns (Separation of Concerns) in JavaScript.
  • Using Git for incremental, well-documented development.
  • Implementing LocalStorage API for client-side data persistence.
  • Building responsive, accessible web interfaces with CSS custom properties and animations.
  • Integrating third-party APIs (QR code generation) into a client-side application.

Future Scope

  1. Backend Integration: Add Node.js/Express server with MongoDB for real, routable short URLs.
  2. User Authentication: Implement login/signup for personal link dashboards.
  3. Custom Aliases: Allow users to choose custom short codes (e.g., snip.link/my-link).
  4. Advanced Analytics: Geographic click tracking, referrer analysis, and time-series charts.
  5. Browser Extension: One-click shortening from any webpage via Chrome/Firefox extension.
