# 🔗 SnipLink — URL Shortener

A lightweight, modern URL shortener built with HTML, CSS, and JavaScript. Shorten long URLs into compact, shareable links with click tracking and history management.

## Features

- **Shorten URLs** — Generate short, unique codes for any long URL
- **Click Tracking** — Track how many times each short link is clicked
- **Copy to Clipboard** — One-click copy for shortened URLs
- **Link History** — View and manage all your shortened links
- **QR Code Generation** — Auto-generate QR codes for each short link
- **Responsive Design** — Works seamlessly on desktop and mobile
- **Local Storage** — All data persists in the browser

## Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Storage**: Browser LocalStorage
- **APIs**: QR Code generation via qrserver.com API

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/your-repo/url-shortener.git
   ```
2. Open `index.html` in your browser — no server required!

## How It Works

1. Enter a long URL in the input field
2. Click "Shorten" to generate a compact link
3. Copy the short link or scan the QR code
4. View all your links in the History section
